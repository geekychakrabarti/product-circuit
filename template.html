Business Process Circuit Mapper — Template

Map any process as an electrical circuit. Edit CIRCUIT_DATA in the <script> to describe your process.

How to use this template

Open this file in a text editor. Find the CIRCUIT_DATA array in the <script> block and replace the placeholder entries with your own process steps. Each step maps to one of the component types below.

Component types — what to use when

source resistor impedance capacitor amplifier blackbox whitebox measurement switch branch ground

Rejected / secondary path

Edit the REJECTED_ELEMENTS array (right below CIRCUIT_DATA) to define what happens on the rejected/secondary branch. This array follows the same format. Typically: a whitebox (inspect why it failed) → ground (process ends).

Tips

• Put source first and ground last.
• Use one branch element where your process has a key decision fork.
• blackbox = stable systems you trust (don't change). whitebox = areas to investigate.
• measurement = KPI checkpoints — place them after key steps.
• Save the file and refresh your browser to see changes.
