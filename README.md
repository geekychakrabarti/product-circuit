# Product Circuit

**A framework for mapping any business or product process as an electrical circuit.**

Product Circuit uses electronics metaphors — resistors, capacitors, switches, transistors — to make process friction visible, communicable, and actionable. Each step in a process maps to a circuit component that captures not just *what* happens, but *why it behaves the way it does*.

## What's in this repo

| File / Folder | Description |
|---|---|
| `template.html` | Blank circuit template — edit `CIRCUIT_DATA` to describe your own process |
| `example.html` | A worked example showing a fully mapped process |
| `A0 x 1/` | Print-ready PDFs at A0 size (single page) — flattened for reliable printing |
| `A1 x 2/` | Print-ready PDFs at A1 size (two pages) — flattened for reliable printing |

## How to use the template

1. Open `template.html` in a text editor
2. Find the `CIRCUIT_DATA` array in the `<script>` block
3. Replace the placeholder entries with your process steps — each step maps to a circuit component type
4. Open the file in a browser to see your circuit rendered
5. Use the Figma file (link below) to produce print-ready layouts

## Circuit metaphor vocabulary

| Component | Process meaning |
|---|---|
| Battery | The driving force — who initiates the process and why |
| Resistor | Friction, delay, or effort in a step |
| Capacitor | A waiting state where items accumulate |
| Switch | A decision point — who decides, what criteria |
| Transistor | A tool, automation, or AI that amplifies throughput |
| Diode | Flow that only goes one way |
| Ground | Process ends here (often on the rejection branch) |
| Meter | A measurement or KPI checkpoint |
